### What I actually do

**Plugin development** — building and maintaining plugins written specifically for legacy PocketMine-MP APIs, filling gaps the newer forks left behind.

**Server architecture** — setting up, configuring, and debugging legacy servers, usually the ones nobody else wants to touch.

**Community guidance** — a lot of this job isn't code. It's answering the same question for the hundredth time and still meaning it.
