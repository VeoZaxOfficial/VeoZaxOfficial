I'm VeoZax — one of the people who never let **legacy PocketMine-MP** die. While most of the ecosystem moved on to newer APIs, I stayed with the old builds: keeping servers online, plugins updated, and the community that grew up around them intact.

These days that means writing plugins for legacy PMMP APIs, helping server owners untangle setups that modern tutorials have forgotten exist, and guiding the people who show up confused and leave with something that actually works.

<img src="assets/divider.svg" width="100%"/>

### What I actually do

**Plugin development** — building and maintaining plugins written specifically for legacy PocketMine-MP APIs, filling gaps the newer forks left behind.

**Server architecture** — setting up, configuring, and debugging legacy servers, usually the ones nobody else wants to touch.

**Community guidance** — a lot of this job isn't code. It's answering the same question for the hundredth time and still meaning it.
